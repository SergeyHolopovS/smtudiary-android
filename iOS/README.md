# SMTU Diary для iPhone

Приложение на SwiftUI для iOS 16 и новее. Использует API расписания СПбГМТУ и сохраняет последнюю успешную загрузку для каждой группы. Внешних зависимостей нет.

1. На Mac откройте `SMTUDiary.xcodeproj` в Xcode 16 или новее.
2. Выберите схему **SMTUDiary** и симулятор iPhone, затем нажмите **Run** (⌘R).
3. Для запуска на устройстве выберите свою команду в **Signing & Capabilities** у цели **SMTUDiary**. Если идентификатор занят, укажите уникальный **Bundle Identifier**.

При первом запуске выберите учебную группу. Позже её можно сменить через кнопку с шестерёнкой. Потяните список вниз, чтобы обновить расписание. Календарь использует московское время.
